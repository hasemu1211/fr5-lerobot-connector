연구와 실험

검증할 질문을 모으고, 비교 조건과 관찰 결과를 연결할 자리를 잡습니다.

  • 수집 조건과 데이터 구성촬영·동작 조건, 분포와 다양성, 데이터 품질에 관한 질문
  • 검토와 선별 방법검토 표본, 변환과 정보 보존, 데이터 선택에 관한 질문
  • 학습 방법과 최적화정책 선택, 학습량과 설정, 비교 조건에 관한 질문
  • 평가와 일반화지표와 관측 단위, 데이터 분할, 실제 작업과의 관계에 관한 질문
  • 후속 데이터와 반복 학습새 관찰의 활용, 추가 수집과 선별, 재평가에 관한 질문

아직 수행하지 않은 연구 질문도 포함합니다. 실제 결과를 채울 때 검증 범위를 함께 확인합니다.

  • 중단과 복구장비·실행·저장·화면에서 생긴 문제와 대응
  • 시간과 자원수집·기록·검증·학습 비용 · 자원 제약과 측정 조건
