실행과 기록

작업 실행기와 기록기

OneJob은 episode 단위의 계획과 로봇 실행을 관리한다. 기록기는 영상·상태·동작을 수집하고 저장한다. 작업 동작과 기록 종료 후의 복귀 동작을 구분하며, 실행 종료와 안전 상태를 확인한 뒤 데이터를 확정한다.

저장 확정은 되돌릴 수 없는 파일 작업이므로 동작 제어의 제한 시간을 그대로 적용하지 않는다. 기록기 응답이나 프로세스 종료를 확인해 저장 결과를 결정한다.

운영 화면

운영 화면과 상태 관리

운영 화면은 서버의 현재 상태를 표시하고 사용자 명령을 전달한다. 로봇 실행과 데이터 저장 상태는 서버가 관리한다.

서버는 화면의 revision·digest와 요청 이력을 검사해 오래된 상태의 명령과 중복 요청을 거부한다. 브라우저 재접속은 상태 조회만 수행하므로 수집 작업을 다시 시작하지 않는다.

구현 근거운영 화면의 상태·재전송 계약서버의 의도 소비

단일 운영자 PC를 전제로 한다. 브라우저 채널 토큰은 사용자 신원 인증이나 학습 사용 권한을 대신하지 않는다.

검토와 학습

데이터 검토·학습 입력 관리

데이터의 기술 품질, 작업 의미, 보존 상태와 학습 사용 권한을 별도로 관리한다. Curator는 선택한 수집 기록의 판정과 원본 경로를 검증해 학습 요청을 만든다. 학습 승인은 별도 모듈에서 처리한다.

학습 모듈은 승인 목록과 선택한 episode, 데이터 분할을 검증한다. 실제 학습 receipt에서 원래 수집 기록과 판정 근거까지 추적할 수 있다.

구현과 실제 입력기존 기록에서 요청 발행실제 학습 입력의 참조

영상 변환 후보의 준비는 기존 수집 기록의 요청 발행과 별도 경로이다. 변환에 필요한 물리 결속은 따로 검증한다.

수집 분석·추천

수집 분석·추천 모듈

수집 조건별 coverage를 분석해 다음 수집 조건을 제안한다. 추천은 작업 초안의 변경 요청으로 변환하며, 실행 권한은 기존 수집 모듈에서 별도로 확인한다.

기존 production 수집 기록 하나를 직접 입력했을 때에는 과거 계획 근거가 없어 UNAVAILABLE을 반환했다. 추천 적용의 코드·합성 데이터 검증과 실제 수집 기록의 적용 여부를 구분한다.

확인한 경계추천의 입력과 발행 경계추천에서 draft 변경 의도로

학습 정책의 실물 실행부터 재수집·재학습 효과까지 이어지는 폐루프는 미검증 범위이다.
