FR5 포트폴리오

1. ZIP 파일 전체를 하나의 폴더에 압축 해제한다.
2. 폴더 안의 index.html을 데스크톱 Chrome 또는 Edge로 연다.

설치·로그인·서버 실행은 필요하지 않다. 이미지, 동영상, 도해, 그래프와 발췌한 근거 자료가 포함되어 있다. 웹 문헌 링크만 인터넷을 사용한다.

검토할 때
- 프로젝트에서 전체 구성을 보고 관심 있는 모듈로 이동한다.
- 시스템의 연결 선택에서 입력·실행 조건·출력을 살펴본다.
- 데이터에서 시점별 관측, Rerun 연결 설명과 영상 변환 전후를 비교한다.
- 학습·평가에서 생성 원리와 실험 결과를 본다.

피드백은 페이지 이름과 소제목, 이해가 끊기는 지점 또는 개선 의견을 보내면 된다. 스크린샷을 함께 보내도 좋다.

이 전달물은 포트폴리오 설명 자료이다. Rerun의 실제 탐색 화면과 연결 근거를 담았으며, 별도 설치가 필요한 Rerun 실행기나 로봇 운영 서버를 포함하지 않는다.
