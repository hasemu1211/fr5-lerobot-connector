# FR5 포트폴리오의 전체 틀

전체 개요, 시스템 구성, 세부 주제 목록을 실제로 오가며 검토하는 로컬 시안이다. 지금은 프로젝트의 큰 범위와 설명의 목적을 구분한다. 개별 성과의 가치, 대표 사례, 내용의 비중과 최종 매체는 정하지 않았다.

사용자가 요청한 방향은 **변하는 증거의 원래 추적 경로는 표현 책임자가 인지하되, 현재 받은 결과를 중심으로 전체 서사를 먼저 고정하지 않는 것**이다. 초기 학습 비교를 앞세운 시안은 이번 산출물에서 제외했다. 그때 소비한 근거와 표현 실험은 `.agent-local/portfolio/`에 참고용으로 보존한다.

의사결정의 근거와 초기 시안의 자가 평가는 [표현 재검토](editorial-review.md)에 있다. 후보 목록은 구현 목록이나 완료 상태표가 아니며, 항목별 페이지 제작을 약속하지 않는다.

## 로컬 확인

외부 패키지나 Learning 출력 없이 정적 파일을 열 수 있다. 사용자 요구에 따라 데스크톱 구성을 대상으로 하며 모바일 전용 제작·추가 검토는 제외한다. 향후 이미지·영상 등 포함 자산을 합친 전달물 전체는 50MB 이하로 관리한다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/portfolio
```

`http://127.0.0.1:8765/`에서 시작한다. 이미 같은 포트폴리오 preview 서버가 동작 중이라면 서버를 중복 실행하지 않고 기존 preview 경로를 사용한다.

## 이 단계의 확인 범위

- 전체 개요에서 시스템 구성과 후보 목록으로 이동하고 돌아올 수 있다.
- 각 페이지와 단락의 목적이 구별되며, 내용의 중요도를 선결하지 않는다.
- 시스템의 분기·독립 작업·재검토 관계와 공통 운용 조건을 살펴볼 자리가 있다.
- 구현 완료·실제 실행·미래 가설을 혼동하는 수치나 상태표를 만들지 않는다.
- 데스크톱에서 직접 렌더하며 탐색 경로와 가독성을 확인한다.

이전 390px CSS viewport 확인은 과거 검토 기록으로만 남긴다. 키보드 입력 검증과 시각적 디자인의 수용 여부는 아직 확정하지 않았다. 이 틀을 마련한 일을 전체 포트폴리오 proof 연결의 완료로 세지 않는다. 제품 source 회귀의 시도와 실패는 기존 Orca handoff에 보존하며, 이 정적 표현물의 검증과 구분한다.
