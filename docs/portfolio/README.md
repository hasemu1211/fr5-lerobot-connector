# FR5 포트폴리오

실제 기록과 시스템·연구 근거를 읽을 수 있는 로컬 포트폴리오를 개발한다. 초기 전체 틀과 후보 목록을 보존하면서 내용·구성·매체를 임시 편집 가설로 직접 만들고 검토한다. 장기 Goal의 완료 기준은 실제 내용을 채운 독자 경험과 중요한 결함의 해결이며, 목록이나 문장 수정만으로 완료하지 않는다.

사용자가 요청한 방향은 **변하는 증거의 원래 추적 경로는 표현 책임자가 인지하되, 현재 받은 결과를 중심으로 전체 서사를 먼저 고정하지 않는 것**이다. 초기 학습 비교를 첫 화면에 앞세운 구성은 철회했다. 현재는 시스템 소개 뒤에 학습·평가를 독립된 기능·연구로 배치한다. 이전 표현 실험은 `.agent-local/portfolio/`에 보존한다.

세부 구성은 주제의 전달 목적에 맞춰 분량과 매체를 고르며 공통 템플릿을 강제하지 않는다. 지금 정리할 중복·용어·탐색 경로와 근거를 더 본 뒤 정할 대표 사례·비중·세부 표현을 구분한다.

의사결정의 근거와 초기 시안의 자가 평가는 [표현 재검토](editorial-review.md)에 있다. 후보 목록은 구현 목록이나 완료 상태표가 아니며, 항목별 페이지 제작을 약속하지 않는다.

## 로컬 확인

현재 실제 내용이 있는 화면은 전체 소개, 시스템, 기록과 검토, 학습과 평가다. 후보 목록 `topics.html`은 편집 재료로 보존하며 최종 독자 경로의 필수 페이지가 아니다.

실제 근거에서 생성한 로컬 preview는 `http://127.0.0.1:8765/`에서 확인한다. HTML/CSS/상호작용과 편집 가능한 draw.io SVG는 이 폴더에 있고, 관측 이미지·수치·원문 열람 화면은 기존 canonical 출력에서 생성한 표현이다. 소스 폴더만 직접 serve하면 생성 자산이 없으므로 현재 완성된 preview와 같지 않다.

재료를 읽는 agent 전용 도구는 worktree의 `.agent-local/portfolio/build_content.py`에 둔다. Learning owner의 frozen observation manifest와 비교 보고서 참조를 검증하고, 기존 PNG를 실제 RGB tensor와 대조한 후 `.agent-local/portfolio/preview/`에 표현을 생성한다. 원본 dataset·checkpoint·판정 파일을 수정하거나 새 학습을 실행하지 않는다. 이 helper와 로컬 절대 경로는 공개 배포용 API가 아니다.

전달할 로컬 묶음에는 독자 화면과 필요한 생성 자산만 포함한다. 원문 열람 화면은 원본 위치·바이트 digest와 발췌 여부를 표시한다. 생성된 수치와 그림은 원본을 소비하는 표현이며 매체별 결과 장부를 두지 않는다. 새 근거를 반영할 때에는 해석과 한계도 함께 재검토한다. 원본 위치를 포함하므로 공개 업로드 전에는 main이 공개 범위를 확인한다. 현재 공개 push/upload 권한은 없다.

## 검토 범위와 남은 일

데스크톱에서 실제 관측·seed·지표·episode를 바꾸고 사진·수치·설명이 일치하는지 확인한다. 각 페이지에서 근거를 열고 관련 부분과 전체로 돌아간다. 원본 결속과 동작 검사는 디자인의 설득력을 대신하지 않으므로 별도로 화면을 보고 비평한다.

모바일 전용 제작·추가 검토는 제외한다. 전달물은 이미지·그림·원문 열람 화면 등 포함 자산 전체 50MB 이하로 관리한다. 초기 390px 확인은 과거 검토 기록일 뿐 현재 검증 범위가 아니다.

작은 시안과 집중 검증을 마칠 때마다 OpenSpec에 결과를 남기되 장기 Goal은 실제 내용과 시각적 완성도, 근거 연결의 중요한 결함을 해결할 때까지 이어간다. 직접 사용자 취향을 반영하며 표현의 개발은 자율적으로 이어간다. main은 통합 사실, 공개 범위와 타 lane의 새 근거를 조율한다. Robotics 전체 suite와 학습 환경 복구는 이 표현 lane에서 반복하지 않는다.

현재 로컬 검토 묶음은 `.agent-local/portfolio/fr5-portfolio-local-review.zip`이다. 압축 해제한 독자 화면과 포함 자산은 7,778,495 bytes이며, 내부 렌더용 HTML과 편집 후보 목록은 제외했다. 운영 화면 전체의 기능 설명, 첫 화면의 대표 매체와 시스템 세부의 연결은 추가 개선 대상이다.
