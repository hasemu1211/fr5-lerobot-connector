Policy Learning

Policy Learning은 승인된 FR5 데이터로 SmolVLA를 학습하고 checkpoint를 오프라인에서 평가한다. 데이터 분할과 정규화 조건을 검증하고, 저장된 processor로 예측 동작의 단위를 복원한다.

이 페이지에서모델 입력과 출력분할·정규화평가 대상 보존동작 생성 원리학습 설정 비교관절·그리퍼 오차

모델 구조

영상·작업 지시를 반영한 동작 생성

Policy Learning은 두 카메라 영상과 작업 지시, 현재 로봇 상태에서 이어질 동작을 예측하도록 SmolVLA를 미세 조정한다. 영상은 물체와 주변 환경을, 작업 지시는 수행할 일을, 상태 값은 현재 관절과 그리퍼 위치를 제공한다.

사전 학습된 시각·언어 모델로 관측의 맥락을 읽고, 동작 생성기로 연속된 관절·그리퍼 값을 출력하는 구조이다. FR5의 시연으로 이 입출력 관계를 학습하며, 예측을 원래 동작 단위로 복원해 비교한다.

입력 토큰과 어텐션 구조

영상·언어 모델(VLM)은 두 카메라 영상, 작업 문장과 로봇 상태를 토큰으로 변환해 맥락 특징을 계산한다. 동작 생성기(Action Expert)는 이 특징을 참조하는 교차 어텐션과 동작 토큰 사이의 관계를 계산하는 자기 어텐션을 번갈아 사용한다.

한 시점의 관측에서 생성하는 출력은 50개 동작으로 이루어진 action chunk이다. FR5의 평가 경로는 checkpoint에 저장된 postprocessor로 정규화를 되돌려 각 출력을 rad·m 단위로 비교한다. 없는 카메라 슬롯은 마스크로 구분한다.

학습 데이터에서 익힌 규칙을 별도 시연으로 평가할 수 있도록 시연 단위로 학습·평가를 나눈다. 정규화 통계는 TRAIN 부분에서만 구해 평가 데이터의 정보가 학습 전처리에 들어가는 것을 막는다. 사용한 목록과 통계를 checkpoint의 실행 기록·processor에 연결해 같은 조건으로 평가를 재현한다.

아래 비교 실험은 26개 시연 중 20개를 학습에, 6개를 개발용 평가에 사용했다. 한 시연 안의 인접 프레임은 외관과 동작이 비슷하므로 프레임을 무작위로 섞어 나누지 않고 시연 단위로 분리한다.

관절 각도와 그리퍼 위치는 단위와 변화 폭이 다르다. 학습 부분에서 각 축의 평균 μ와 표준편차 σ를 계산해 (x − μ) / σ로 정규화한다. 평가 시연은 이 통계에 포함하지 않는다. 예측 결과는 checkpoint에 저장한 같은 통계로 다시 rad·m 단위로 복원한다.

데이터 확장과 평가 대상 보존

데이터를 늘린 뒤 평가 대상까지 바뀌면, 점수 차이가 추가 데이터의 효과인지 평가 난이도의 차이인지 판단하기 어렵다. 기존 평가 시연을 고정하고, 새 조건의 평가가 필요하면 별도로 정한 평가 시연을 합친다. 같은 비교에 참여하는 모델은 이 목록을 함께 사용한다.

Curator는 원본 시연의 대응 정보와 평가 목록을 학습 요청에 연결한다. Training Entrypoint는 각 원본의 TRAIN·EVAL 배정을 보존한 목록을 통합 데이터의 현재 번호로 바꾸어 데이터 로더에 전달한다. 정규화 통계는 TRAIN에서 계산하며, 최종 평가 목록의 시연은 모두 제외한다.

원본 식별과 분할 검증

평가 시연은 원본 데이터 식별값, 원래 시연 번호와 내용 식별값으로 고정한다. 기존 cohort만 쓰면 그 평가 대상을 유지하며, 독립적으로 정한 cohort를 합칠 때는 각 TRAIN·EVAL 배정을 보존한다. 학습 전에 원본 연결을 다시 확인해 평가 대상의 누락, 원본의 중복·변경을 거부한다. 이 표는 구현 원리이며, 아래 학습 실험은 당시의 20/6 분할로 수행한 결과이다.

학습 설정별 평가 결과

기존 시연으로 학습을 더 진행했을 때 정책의 예측이 어떻게 달라지는지 비교했다. 먼저 기본 모델에서 3,000·10,000 step을 학습하고, 이후에는 10,000-step 가중치를 재사용해 batch를 늘린 추가 학습을 수행했다. 학습된 가중치를 활용하면서 처리 효율과 예측 품질을 함께 확인하려는 실험이다.

초기 비교에서는 평균 loss가 0.2585 → 0.2164로 감소했다. 추가 학습에서는 0.2318·0.4138로 증가해, 이 비교에서는 10,000-step 모델을 기준으로 유지했다.

추가 학습은 batch를 1에서 4로 늘리고 optimizer·학습률 진행 상태·난수·데이터 읽기 위치를 초기화한 warm-start이다. 변경된 학습 조건을 함께 고려해야 하므로, 손실 증가를 batch 크기나 데이터 부족 하나의 원인으로 단정하지 않는다.

학습 손실과 함께 실제 동작 단위의 오차를 확인해 어느 관절·그리퍼에서 차이가 생겼는지 분석한다. 전체 평균과 개별 축·시연의 결과를 함께 비교한다.

MAE는 각 예측 오차의 절댓값을 평균해 전반적인 차이를 나타낸다. RMSE는 오차를 제곱해 평균한 뒤 제곱근을 취하므로 큰 오차에 더 민감하다. 한 축에서 MAE가 줄고 RMSE가 늘었다면, 평균적인 차이의 감소와 일부 큰 오차가 함께 나타날 수 있다.

저장 관측에서 예측한 동작을 checkpoint의 postprocessor로 복원해 rad·m 단위로 비교했다. 각 시연의 세 시점과 두 seed를 사용하며, 관측 상태를 그대로 유지한 경우를 비교 기준으로 둔다. 아래 수치는 Rollout loader 수정 전 평가 결과이다.
