실물 작업영역 등록

종이의 위치·각도와 로봇의 입력을 같은 정의에서 생성하고, 실물 기준점으로 등록한 사례다. 아래 값은 저장소의 측정·등록 설정에서 발췌했다.

두 점으로 축을 정하고, 다른 점으로 확인

A4 가로 297×210mm에 CENTER=(148.5,105), X_REF=(277,105), Y_CHECK=(20,185)mm를 둔다. CENTER→X_REF를 주어진 테이블 평면에 투영해 X축을 만들고, 평면 법선과 X축의 외적으로 Y축을 만든다. Y_CHECK는 축 계산에 넣지 않고 예상 위치와 측정 위치의 잔차를 확인한다.

현재 등록의 평면 법선은 [0,0,1]이다. 세 점으로 임의의 평면을 새로 맞추는 방식과 구분한다. 위치·yaw 변환은 같은 시트 계열과 TCP 설정에 연결된다.

좌표 등록과 FK 검사의 역할

등록 경로는 같은 관절 시각의 base_link→wrist3_link TF와 도구→TCP 변환을 합성해 기준점 좌표를 얻는다. /compute_fk로 로봇 전체 도달영역을 탐색하는 방식은 아니다. 별도 실행 계층은 MoveIt의 GetPositionFK를 사용해 실행·접촉 형상을 계산한다. 영역 안의 배치 가능성과 로봇 경로의 도달성·충돌 검사는 별개다.

인쇄 보정과 서로 다른 작업영역 범위

100mm 기준 막대가 96mm로 인쇄되면 생성기는 104.166667% 보정본을 만든다. 재인쇄한 막대는 다시 측정한다. 이 printcal 예와 위 셀의 100mm 시트 계열을 동일한 인쇄물로 취급하지 않는다.

기본 5×3 격자는 35mm 간격으로 x±70/y±35mm를 사용한다. RED/BLUE 영역판의 다각형 x±133.5/y±85mm는 별도 범위이며, 실제 허용 물체 중심은 선택 yaw·물체 외곽·보정 여유로 다시 계산한다.

측정 방법을 바꾸어도 남는 데이터 연결

현재 좌표계는 알고리즘 시연 궤적 생성이 1차 목적이다. 제한된 위치·각도·물체 조건을 실물에서 반복하고 시연·평가 기록에 같은 조건으로 남기는 프로토타입이기도 하다.

확장 방향은 A4 기준점 측정을 비전·다른 측정 입력으로 연결하는 것이다. AprilTag는 카메라 기준의 태그 위치·방향·식별을 제공해 작업면 등록 후보가 되고, FoundationPose는 CAD 또는 소수 참조 영상으로 새로운 물체의 6D 자세 추정·추적을 다뤄 물체 관측의 후보가 된다.

카메라와 로봇 좌표계의 보정, 측정 시각·대상·불확실성의 연결은 각 입력 어댑터에서 구현·검증한다. 기존 작업 조건·시연·진단의 대응을 재사용하는 확장 방향이며 현재 자동 인식 기능을 뜻하지 않는다.
