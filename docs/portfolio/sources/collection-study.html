추가 수집의 효과를 비교하는 설계

FR5의 다음 질문은 취약 조건의 시연을 보강했을 때 정책이 실제 작업을 더 잘 수행하는가이다. 아래 연구는 그 질문을 구체화하는 참고다. 각 논문의 점수 계산이나 데이터 선택 알고리즘을 현재 FR5 구현으로 제시하지 않는다.

연구마다 데이터의 가치를 판단하는 기준이 다르다

연구핵심 관점FR5 실험에 반영할 판단
CUPID · CoRL 2025평가 rollout을 이용해 시연이 정책의 기대 보상에 주는 영향을 추정한다.수집량이나 데이터 검사 통과보다, 학습 뒤 실제 작업 결과를 판단 기준으로 둔다.
DataMIL · 2025 / ICLR 2026정책에 유용한 데이터를 선택하며, 선택 과정의 실행 비용을 줄이기 위해 목표 작업의 대리 손실을 사용한다.오프라인 비교는 후보를 좁히는 진단으로 활용하되 실물 성공을 대신하지 않는다.
Quality over Quantity · 2026.03검증 시연에 대한 기여를 추정한다. 높은 점수의 개별 순간만 모으기보다 시연 단위로 집계해 행동의 연속성과 범위를 보존한다.추가 데이터는 완전한 작업 시연으로 구성하고, 파지 등 일부 순간만 강조하다 다른 동작 구간이 사라지지 않게 한다.
RoboDrop · 2026.09 사전공개작업 의미와 시각적 상호작용 맥락이 가까운 검증 표본을 기준으로, 학습 중 gradient compatibility를 평가한다.모든 실패를 한 종류로 묶지 않고 작업·배치와 실행 구간을 구분해 해석한다. 자동 맥락 검색과 gradient 기반 점수는 현재 구현이 아니다.

앞의 방법들은 주로 이미 모인 데이터의 선별을 다룬다. FR5에서 다음 물리적 수집 조건을 고르는 문제와 동일하지 않으므로, 논문의 성능 향상 수치를 FR5의 예상 효과로 사용하지 않는다.

비교에서 바꾸는 것과 고정하는 것

바꾸는 것은 추가 시연의 조건 배분이다. 균형 수집은 허용 작업영역의 위치·각도를 분산하고, 표적 수집은 개발 평가에서 확인한 취약 조건을 우선한다. 두 경로는 같은 초기 데이터·출발 정책에 각각 추가한 데이터로 학습한다.

  • 고정: 물체·작업·보정, 초기 데이터, 추가 시연 수, 모델과 학습 설정, 최종 평가 조건.
  • 분리: 표적 선택에 사용하는 개발 평가와 최종 효과를 판단하는 평가.
  • 반복: 독립 학습 seed와 같은 평가 조건의 여러 실행. 추론 noise seed만 바꾼 것은 독립 학습 반복으로 세지 않는다.
  • 판단: 전체 및 취약 조건별 작업 성공, 중단·복구와 사람 개입, 유효 시연당 실제 취득 시간.

이는 향후 실험 설계다. 같은 데이터 개수와 같은 현장 비용은 별개이며, 결과가 없는데 우열이나 예상 성공률을 그리지 않는다.

현재 구현으로 연결되는 부분

작업영역의 위치·각도 생성, 시연 단위 기록, 원본·평가 대상 보존, 고정 관측의 정책 비교와 원본 조건의 재수집 추천이 기반이다. 실물 정책 평가와 추가 수집·재학습을 연결해 이 실험을 완성하는 것이 다음 단계다.

원본 조건의 재수집 추천 · 평가 대상 보존과 정책 비교
