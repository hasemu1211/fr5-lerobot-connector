데이터 시스템

FR5 로봇의 시연을 수집하고, 검토한 데이터로 정책을 학습·평가하는 시스템이다. 로봇 제어, 다중 센서 기록, 데이터 관리와 학습 실행을 연결한다.

프로젝트 구성

로봇 운용과
학습 데이터 파이프라인

수집 실행기는 작업 계획과 로봇 동작을 관리한다. 기록기는 영상·관절·그리퍼 신호를 시간 기준에 맞춰 저장한다. 검토 모듈은 데이터 품질과 작업 의미를 확인하고, 학습 모듈은 승인된 데이터와 평가 조건을 검증한다.

실행 실패와 저장 실패를 구분하고, 데이터 원본부터 학습 입력까지 추적할 수 있도록 설계했다. 로봇 운용의 안정성과 모방학습 실험의 재현성을 함께 다룬다.
