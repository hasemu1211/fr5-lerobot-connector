로봇 시연 수집·학습 시스템

수집 조건을 계획하고, 영상과 로봇 상태를 같은 시간 기준으로 기록해 FR5 시연을 학습 데이터로 만드는 시스템이다. 수집한 원본을 선별·학습·평가에 연결하고, 같은 관측에서 정책의 동작 예측을 비교한다.
