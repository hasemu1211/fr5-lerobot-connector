          다음 캠페인 계획

          현재 조건을 복사합니다. 그대로 사용하거나 계획 화면에서 필요한 항목만 바꿀 수 있습니다.

          CENTER → X_REF → Y_CHECK

          작업영역 관리

          이 화면은 로봇 동작 명령을 보내지 않습니다. 티치 펜던트 또는 수동 방식으로 TCP를 표시된 위치에 놓으세요. 캡처 버튼은 현재 자세만 읽습니다.
            화면은 현재 상태를 표시하고 요청만 보냅니다.수집 완료는 학습 사용 승인이 아닙니다.
