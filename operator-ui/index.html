01 · 먼저 확인

환경 준비

현재 로봇, 그리퍼, 카메라 상태와 필요한 조치를 표시합니다.

    카메라 역할

    연결된 카메라가 보는 위치만 지정하세요. 녹화 설정은 자동으로 맞춥니다.

    02 · 조건 선택

    수집 계획

    등록된 작업, 물체, 동작 설정을 선택합니다. 사용할 수 없는 항목에는 이유가 표시됩니다.

    작업영역 관리새 작업영역의 이름과 CENTER, X_REF, Y_CHECK를 등록합니다.
    시작 자세 관리현재 관절 자세를 등록하고 수집에 사용할 자세를 선택합니다.
    수집 조건
    녹화 카메라환경 준비에서 지정한 역할로 자동 설정됩니다.

    물체와 잡기 항목은 등록된 프로필입니다. 작업 설명은 현재 화면 상태에 포함된 레시피 정보가 있을 때만 표시됩니다. 항목을 바꾸면 호환되지 않는 다른 항목도 함께 조정될 수 있습니다.

      03 · 실행 승인

      계획 확인

      표시된 범위에서 에피소드를 순서대로 실행합니다. 조건을 바꾸면 새 계획이 필요합니다.

      에피소드 실행 순서

        수집 시작을 누르면 표시된 에피소드가 순서대로 실행됩니다.실행 중에는 다음 에피소드가 시작되기 전에 즉시 중단할 수 있습니다.

        04 · 자동 연속 실행

        실행

        각 에피소드 완료를 앱이 확인하면 다음 에피소드가 자동으로 시작됩니다.

        05 · 수집 뒤 확인

        결과

        수집이 끝나면 기술 검사를 통과한 에피소드를 사용 후보·제외·보류로 분류할 수 있습니다.

          06 · 프로세스 재시작 없음

          다음 수집

          완료한 실행은 그대로 보존하고 새 수집 계획을 만듭니다.

          다음 수집 계획

          완료한 수집의 조건을 새 계획에 복사합니다. 계획 화면에서 필요한 항목만 바꿀 수 있습니다.

          기술 정보

          CENTER → X_REF → Y_CHECK

          새 작업영역 등록

          이 화면은 로봇을 움직이지 않습니다. 티치 펜던트 또는 수동 방식으로 TCP를 표시된 위치에 놓으세요. 캡처 버튼은 현재 자세만 읽습니다.

            현재 관절 자세

            시작 자세 관리

            자세 캡처는 로봇을 움직이지 않습니다. 티치 펜던트 또는 수동 방식으로 원하는 자세를 만든 뒤 현재 관절값을 등록하세요.

            수집에 사용할 시작 자세

            화면은 현재 상태를 표시하고 요청만 보냅니다.수집 완료는 학습 사용 승인이 아닙니다.
